# @electron-three-boiler/content-processor

Composant React réutilisable - Transforme des objets algorithmiques en Map avec des objets THREE.js

## Installation

```bash
npm install github:username/electron-three-boiler#@electron-three-boiler/content-processor@0.1.0
```

Ou dans `package.json` :

```json
{
  "dependencies": {
    "@electron-three-boiler/content-processor": "github:username/electron-three-boiler#semver:^0.1.0"
  }
}
```
